PASO 5 — Representación impresa (FORMATO DGII)
==============================================

DGII rechazó el formato anterior. Las RI deben seguir los modelos ilustrativos:
https://dgii.gov.do/cicloContribuyente/facturacion/comprobantesFiscalesElectronicosE-CF/Documentacin%20sobre%20eCF/Informe%20y%20Descripci%C3%B3n%20T%C3%A9cnica/Representaci%C3%B3n%20Impresa%20(Modelos%20ilustrativos).pdf

Modelos usados en certificación BUENOHOTEL:
  1.1  → tipos 31, 41, 43, 44, 45, 46, 47
  1.5  → tipo 33 (Nota de Débito)
  1.6  → tipo 34 (Nota de Crédito)
  2.1  → tipo 32 >= RD$250mil
  2.2  → tipo 32 < RD$250mil

Regla clave (modelo 1.1): columna Valor = precio × cantidad SIN ITBIS.

Generar en dgi\:
  npm install
  npm run paso5-generar

Salida: salida\representacion-impresa\
  → Abrir cada HTML → Ctrl+P → Guardar como PDF
  → Subir los 11 PDF al portal Paso 5

Requisito: XML firmados en salida\ecf-firmados\

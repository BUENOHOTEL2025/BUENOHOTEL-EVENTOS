PASO 3 — Ejecutar
-----------------

OPCION A (recomendada) — doble clic, SIN npm:
  ejecutar-notas-pendientes.bat

OPCION B — desde CMD (tampoco uses "npm run" con el .bat):
  cd C:\Users\claud\OneDrive\Desktop\dgi
  ejecutar-notas-pendientes.bat

OPCION C — todo con npm (un solo comando):
  cd C:\Users\claud\OneDrive\Desktop\dgi
  npm install
  npm run notas

  (NO escribir: npm run ejecutar-notas-pendientes — ese nombre no existe en npm)

Hace automáticamente:
  1) npm install (solo la primera vez)
  2) Firma los 6 XML con su .p12 (tag correcto <eNCF>)
  3) Envía a DGII en orden: padre → nota (6 envíos)
  4) Guarda resultado en salida\envio-resultados\

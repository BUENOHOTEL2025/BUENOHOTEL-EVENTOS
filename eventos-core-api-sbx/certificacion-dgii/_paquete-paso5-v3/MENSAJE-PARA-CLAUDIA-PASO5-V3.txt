Instalación:
  1) Descomprime SOBRE dgi\
  2) npm install
  3) npm run paso5-generar

Al imprimir PDF (Ctrl+P):
  - Verifique que arriba-izquierda diga "Razón Social Emisor: ..."
  - Márgenes: Predeterminado
  - Activar "Gráficos de fondo" si el navegador lo ofrece

Luego subir los 11 PDF al portal Paso 5.
